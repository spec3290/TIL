# 트리
트리는 자료구조 중 비선형적인 자료구조이다.
주로 계층 간의 관계를 표현하기 위해 사용된다.

# 트리 용어
* 루트 노드 :
   트리 계층에서 가장 높은 노드를 지칭함.
* 서브 트리 :
  루트 노드 아래에 있는 트리.
* 간선 :
  노드를 서로 잇는 선.
* 부모노드 : 어떤 노드 상위에 연결된 노드

* 자식노드 : 어떤 노드 하위에 연결된 노드

* 형제노드 : 같은 레벨에 위치하는 노드

* 단말노드 : 자식 노드가 없는 노드.

* 조상노드와 후손노드: 특정한 노드의 상위 계층/하위 계층에 존재하는 모든 노드

* 차수 : 어떤 노드가 가진 자식 노드의 수(자식의 후손 미포함)

* 트리의 차수 : 트리가 가진 노드의 차수 중 가장 큰 값.
