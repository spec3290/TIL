# 스택이란?
컴퓨터에서 많이 사용되는 자료구조임
입출력 형태는 후입선출. 맨 위에서만 입출력이 일어나고
중간에서는 삭제가 불가능.
*급식실 식판, 프링글스 등을 예로 들 수 있다*
## 스택의 구조
1. 입출력이 일어나는 상단
2. 스택의 바닥 부분인 스택 하단
3. 스택에 요소가 하나도 없을 경우에는 공백 스택이다.
* * *
# 스택의 사용
재귀 알고리즘, 백트래킹
* * *
# 큐란?
먼저 들어온 데이터가 먼저 나가는 구조. 선입선출임
마찬가지로 중간에서 삭제가 불가능함
큐는 뒤에서 새 데이터가 입력되고 앞에서 삭제됨.
삽입은 rear에서, 삭제는 front에서.
