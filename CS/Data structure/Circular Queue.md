# 원형 큐
일반적인 선형 큐에서는 rear와 queue를 이용한 삽입/삭제 과정에서 데이터가 rear 쪽에 몰리는 현상이 나타남.
그렇기에 요소들을 이동시켜야 하는데 이 과정에서 코드가 복잡해지고 많은 시간이 걸린다.
* * *
이를 해결하기 위해 사용되는 자료구조가 *원형 큐*이다.
기존의 선형 큐에서는 rear 쪽에 데이터가 몰리면, 이동시켜야 했지만 원형 큐는 큐가 원형의 형태를 띄고 있기에 이러한 문제들을 해결해준다.
즉, front와 rear가 배열의 끝에 도달하면, 다음에 증가되는 인덱스는 0이 되는 것이다.
# 공백 상태와 포화 상태 조건
rear == front ->원형 큐가 비었음을 의미함.
(rear+1)%MAX_QUEUE_SIZE==front -> 원형 큐가 가득 찼음을 의미함
* * *
원형 큐는 배열이 비어있거나, 가득 찼는지를 확인하기 위해 배열 한 칸은 무조건 비워놓는다.
비워놓지 않으면, 가득 차게 되었을 때 rear와 front가 같은 인덱스에 위치하므로 가득 찬 상태인지, 빈 상태인지 구별하지 못한다
